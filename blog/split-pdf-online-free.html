  • Reduce file size — break a large PDF into smaller, more manageable files
  • Share selectively — send only relevant pages instead of the entire document

Browser-Based PDF Splitting: How It Works

Modern browsers can process PDFs natively using pdf-lib, a JavaScript library that runs entirely in the browser. When you split a PDF using browser-based tools:

  1. Your PDF is loaded into browser memory — never uploaded to any server
  2. pdf-lib reads each page and creates new PDF documents containing only the pages you selected
  3. The split PDFs are generated locally and downloaded via your browser's download API

Since all processing happens client-side, even large PDFs with hundreds of pages can be split in seconds.

Two Ways to Split PDFs

1. Extract Specific Page Range

Enter a page range (e.g., "1-5" or "3,7,9-12") to extract only those pages into a single new PDF. This is perfect for pulling chapters from a book or specific sections from a report.

2. Split All Pages (Batch)

Split every page of your PDF into individual PDF files, then download them all as a ZIP archive. This is ideal when you need each page as a separate document — for example, separating a batch of signed forms.
